OpenClaw Pivot: Dùng ChatGPT Plus Login Thay Thế Claude API Sau Khi Bị Anthropic Cấm

Chỉ hơn 1 tháng sau, OpenClaw pivot sang ChatGPT Plus login — dùng subscription để truy cập Codex, near-unlimited, không cần API key. OpenAI ủng hộ openness, Anthropic lock-down. Mở đầu: Sự Cố Anthropic Ban OpenClaw

Ngày 4 tháng 4 năm 2026, Anthropic chính thức cấm OpenClaw — một công cụ mã nguồn mở — khỏi việc sử dụng Claude Pro/Max subscriptions với external tools. Đây là đòn giáng mạnh vào cộng đồng developer, vì trước đây họ có thể dùng Claude thông qua OpenClaw với một flat-rate monthly fee thay vì trả theo token API.

Nhưng chỉ hơn một tháng sau, OpenClaw đã pivot thông minh: giờ bạn có thể sign in với tài khoản ChatGPT Plus ($20/mo) hoặc Pro ($200/mo) và dùng subscription đó để truy cập Codex — near-unlimited usage, không cần API key riêng. Một cú đánh thẳng vào sự khác biệt giữa OpenAI (openness) và Anthropic (lock-down).

OpenClaw Là Gì?

OpenClaw không phải là một wrapper API đơn giản. Đây là một AI gateway & proxy mạnh mẽ, cho phép quản lý và switch giữa hàng loạt nhà cung cấp AI thông qua một giao diện thống nhất.

Screenshot từ trang docs cho thấy danh sách providers dài: OpenAI, Perplexity, Qwen, Runway, SGLang, StepFun, Tencent Cloud, Qianfan, và nhiều nền tảng khác. Giao diện thiết kế theo phong cách "hacker/developer" với dark mode, font monospace, bố cục 3 cột quen thuộc của documentation site chuyên nghiệp.

Điểm đáng chú ý: trong mục l có dòng "GPT-5 prompt contribution" — dự án đã chuẩn bị sẵn cho mô hình chưa ra mắt, cho thấy tầm nhìn dài hạn.

Timeline: Từ Ban Đến Pivot

🚫 Trước 4/4/2026

OpenClaw cho phép dùng Claude Pro/Max subscriptions thông qua tool. Người dùng trả flat fee, near-unlimited usage.

✅ Sau 2/5/2026

OpenClaw pivot sang ChatGPT Plus login. Dùng subscription để truy cập Codex, không cần API key, vẫn near-unlimited.

Chi tiết thay đổi từ Anthropic

4 tháng 4, 2026: Anthropic thông báo cấm hoàn toàn việc sử dụng Claude Pro/Max subscriptions với external tools như OpenClaw. Điều này có nghĩa:

  • Người dùng OpenClaw không còn truy cập Claude thông qua subscription
  • Nếu muốn dùng Claude, phải trả phí theo usage API — đắt đỏ, khó quản lý
  • Mất đi lợi thế chính của OpenClaw: flat-rate unlimited plan

Giải pháp pivot của OpenClaw

2 tháng 5, 2026: OpenClaw công bố có thể sign in với ChatGPT Plus/Pro account. Cách hoạt động:

  1. Đăng nhập bằng tài khoản ChatGPT Plus/Pro (không cần API key)
  2. OpenClaw dùng subscription để truy cập Codex (OpenAI's coding agent)
  3. Near-unlimited requests trong phạm vi plan
  4. Flat monthly fee — không trả theo token

Opens vs Closed: Cuộc Chiến Triết Lý

Sự pivot này không chỉ là một feature mới — nó là minh chứng rõ ràng cho sự khác biệt giữa hai trại lớn:

🦞 OpenAI — Opens & Accessibility

OpenAI không lock down việc truy cập Codex thông qua third-party agents. Họ ủng hộ sự linh hoạt, cho phép cộng đồng build tool xung quanh ecosystem. ChatGPT Plus login là một cánh cửa mở.

🦀 Anthropic — Closed & Control

Anthropic lock-down hoàn toàn từ 4/4/2026. Đẩy người dùng sang pay-per-use API đắt đỏ, không còn flat-rate unlimited. Chiến lược giữ chặt quyền kiểm soát.

@BriefKitDev đã tóm tắt bằng meme: OpenAI treat OpenClaw as Larry the Lobster (open, welcoming), còn Anthropic treat it as Mr.Krabs (closed, greedy). Cộng đồng hiểu rõ sự tương phản này.

Điểm Cần Tỉnh Táo: Rủi Ro Của Pivot

Mặc dù pivot thông minh, có vài điểm cần cân nhắc trước khi commit:

  • Phụ thuộc vào OpenAI subscription: Bạn phải có ChatGPT Plus/Pro để dùng OpenClaw. Điều này không còn hoàn toàn "open" — bây giờ nó gate behind OpenAI paywall.
  • Không còn Claude support: Nếu bạn trung thành với Claude, OpenClaw không còn là lựa chọn feasible nếu không trả API riêng.
  • Security & Privacy: Đăng nhập qua tài khoản ChatGPT có thể làm nhiều người e ngại về quyền truy cập dữ liệu.
  • Vòng xoay lock-in: OpenAI cũng có thể thay đổi terms trong tương lai — OpenClaw sẽ phải pivot lần nữa.
