Nous Ra Hermes Agent “The Interface Release”: Cuộc Chiến Agent Đang Chuyển Từ Model Sang Giao Diện

24/04/2026 9 phút đọc Nous Research, AI Agents

⚡ Tóm tắt nhanh

Nous Research vừa ra Hermes Agent v0.11.0 với cái tên cực đáng chú ý: The Interface Release. Đây không chỉ là một đợt update tính năng lớn với hơn 700 PR merge, TUI viết lại bằng React/Ink, plugin surface mở rộng mạnh, Bedrock support, GPT-5.5 qua Codex OAuth và Gemini CLI OAuth. Cái đáng nói hơn là product signal đằng sau cái tên này: khi model đang dần thành commodity, lớp interface, orchestration và execution layer mới là nơi agent tạo khác biệt thật.

Phần lớn các tool AI thích khoe model mới, benchmark mới hoặc reasoning mới. Hermes lần này chọn cách khác: đặt tên hẳn bản phát hành là “The Interface Release”. Chỉ riêng cái tên đó đã nói lên một quan điểm sản phẩm rất rõ.

Nó ngụ ý rằng bottleneck của agent không còn nằm thuần ở raw capability nữa. Vấn đề giờ là: agent có dễ điều khiển không, có nhìn được trạng thái không, có plugin đủ sâu không, có steer được giữa chừng không, có lắp ghép được nhiều provider và workflow thật không.

Video launch gốc từ thread của Nous Research. Mình nhúng video thật vào bài thay vì chỉ chụp poster.

1. “The Interface Release” là product signal, không chỉ là tên gọi màu mè

Nếu đọc nhanh changelog, bạn sẽ thấy một đống tính năng: TUI mới, transport layer mới, plugin hooks mới, dashboard plugin system, Bedrock, GPT-5.5, Gemini OAuth, QQBot, shell hooks, webhook direct-delivery, smarter delegation. Nhưng nếu chỉ đọc như checklist, bạn sẽ bỏ lỡ phần hay nhất.

Phần hay nhất là Nous đang nói thẳng: giao diện cộng tác giữa người và agent mới là nơi cuộc chơi bắt đầu phân hóa.

Năng lực model vẫn quan trọng, nhưng khi model nào cũng ngày càng mạnh, lợi thế thật sẽ chuyển sang lớp điều phối: interface, context surfacing, observability, steerability, hooks và plugin surface.

2. Hermes đang dày lên ở đúng lớp execution layer

Release notes của Hermes v0.11.0 khá nặng đô:

  • TUI interactive CLI được viết lại bằng React/Ink,
  • transport layer được tách riêng để hỗ trợ provider clean hơn,
  • native AWS Bedrock,
  • thêm nhiều inference path mới như Gemini CLI OAuth, Vercel AI Gateway, NVIDIA NIM,
  • GPT-5.5 qua Codex OAuth,
  • plugin surface nở mạnh với command registration, tool dispatch, result transform, dashboard tabs,
  • /steer để nắn agent giữa chừng,
  • dashboard có plugin system và live theme switching.

Nói gọn: Hermes không chỉ thêm model. Nó đang xây cả tầng thao tác quanh model.

Ảnh release note từ thread. Nội dung nhìn nhỏ, nhưng cái tên “The Interface Release” mới là hook quan trọng nhất.

3. Điểm đáng tiền nhất không phải GPT-5.5 support, mà là cách Hermes hấp thụ model mới

Nhiều người sẽ nhìn vào dòng “GPT-5.5 over Codex OAuth” rồi nghĩ đây là headline chính. Thật ra không hẳn. GPT-5.5 support là một miếng ngon, nhưng nó không phải linh hồn của release.

Linh hồn nằm ở việc Hermes đang xây một kiến trúc đủ mở để hấp thụ model mới nhanh và bớt đau hơn: model picker live discovery, transport abstraction, nhiều provider path, auxiliary models UI, plugin hooks và orchestration layer rõ hơn.

Nói cách khác, Nous không chỉ hỏi “model nào mạnh hơn?”. Họ đang hỏi câu khác hay hơn: khi model mới xuất hiện, agent của mình hấp thụ và triển khai nó nhanh đến mức nào?

4. Đây là lý do “interface” đang trở thành chiến trường thật

Khi ai cũng có thể gọi API của model frontier, phần khó hơn không còn là có model hay không. Phần khó là:

  • người dùng thấy được agent đang làm gì không,
  • can thiệp giữa chừng có mượt không,
  • tool/plugin có đủ sâu để thành workflow thật không,
  • giao diện có giúp con người trust hệ thống hơn không,
  • và nhiều agent có phối hợp với nhau mà không tự phá filesystem không.

Hermes v0.11.0 chạm đúng những chỗ đó: observability overlay cho subagent, /steer cho mid-run correction, shell hooks cho lifecycle control, dashboard tabs từ plugin, transport layer riêng cho provider complexity. Đây đều là những thứ nghe không sexy bằng benchmark, nhưng mới là thứ quyết định agent có dùng thật được hay không.

🧠 Ý chính

Nếu các model đang dần bị hàng hóa hóa, thì Hermes đang cố lấy lợi thế ở lớp sản phẩm nằm trên model: interface, pluginability, orchestration và execution ergonomics.

5. Hơn 700 PR merge không chỉ là tốc độ ship, mà là tín hiệu về chiến lược

Theo Teknium, đây là “our biggest release yet” với hơn 700 PR merge. Con số đó tự nó chưa nói lên chất lượng, nhưng nó cho thấy một điều: Hermes đang được đẩy như một platform sống, không phải một CLI nhỏ thêm vài command mỗi tuần.

Khi một agent tool bắt đầu có transport layer riêng, plugin API đủ rộng, dashboard extensibility, nhiều provider path và subagent orchestration nghiêm túc, nó đang từ tool chuyển thành execution environment.

6. Chỗ cần tỉnh táo: ship nhanh không tự động đồng nghĩa UX tốt

Tất nhiên, gọi tên release là “The Interface Release” không có nghĩa interface đã solved. Ship nhanh quá đôi khi còn làm UX nứt nhiều hơn. Một vài reply trong thread cũng chạm vào chuyện framework choice, model naming confusion hay nhu cầu computer use sâu hơn.

⚠️ Chỗ cần soi tiếp

Hermes đang đi đúng hướng nếu mục tiêu là biến agent thành công cụ làm việc thật. Nhưng để thắng dài hạn, họ không chỉ cần nhiều hooks hơn hay nhiều provider hơn. Họ cần biến độ phức tạp đó thành trải nghiệm dễ hiểu, ít ma sát và đủ đáng tin để dùng mỗi ngày.

7. Chốt lại

Hermes Agent v0.11.0 đáng chú ý không chỉ vì thêm GPT-5.5, Bedrock hay Gemini OAuth. Nó đáng chú ý vì Nous Research đang phát đi một product thesis rất rõ: cuộc chiến agent đang chuyển từ model sang interface.

Và nói thật, mình nghĩ đây là một thesis đúng. Model mạnh hơn sẽ còn tiếp tục ra đều. Nhưng thứ khiến agent thành sản phẩm thật sẽ nằm ở lớp giữa con người và model: giao diện, điều phối, khả năng quan sát, khả năng steer, khả năng mở rộng qua plugin và cách workflow được đóng gói.

🎯 Chốt một câu

Hermes không chỉ đang thêm tính năng cho agent. Nó đang cố biến interface của agent thành moat.
