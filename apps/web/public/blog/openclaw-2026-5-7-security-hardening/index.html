OpenClaw 2026.5.7: Bảo Mật Thắt Chặt, Telegram Và Plugin Được Củng Cố

08/05/2026 5 phút đọc OpenClaw, Security, Telegram, Plugin

TL;DR

OpenClaw 2026.5.7 là bản release tập trung vào bảo mật và độ tin cậy: native command auth thắt chặt, Telegram access groups được củng cố, cron JSON cleanup và plugin install/update hardening. Không có feature mới nổi bật, nhưng những bản vá này giúp hệ thống ít bị "spooky action at a distance" hơn.

🔐 Native Command + Active Memory Auth Tightened

Owner enforcement giờ áp dụng cho native command handlers. Global Active Memory toggles yêu cầu admin scope. Điều này nghe kỹ thuật, nhưng thực ra rất quan trọng: trước đây có thể có tình huống lệnh native chạy sai ngữ cảnh hoặc memory bị toggle bởi ai đó không có quyền. Giờ thì không.

📣 Telegram Access Groups Fixed

accessGroup:* allowlists giờ apply across DMs, groups, native commands, và callbacks trước khi check numeric sender. Điều này giúp shared bot ops dễ quản lý hơn mà không cần config spaghetti. Nếu bạn dùng Telegram với OpenClaw trong nhóm, đây là bản cập nhật đáng chú ý.

🧰 Channels List + Cron JSON Cleaned Up

openclaw channels list giờ là channel-only, với --all cho bundled/catalog channels và rõ ràng installed/configured/enabled state. Cron JSON cũng được computed status, nên scripts không còn phải guess.

🔌 Plugin Install/Update Repairs Hardened

Managed npm mutations giờ dùng stable lifecycle shell giống package updates. Rollback/repair paths hoạt động predict hơn. Như chính team nói: "The best plugin bug is the one you never meet."

Phản ứng cộng đồng

Thread có vài phản hồi đáng chú ý. @popeyesbiscuits nói đây là "updates that save you from yelling at your computer later". @LastHuman67 thì lo ngại hơn, nói mỗi lần update lại thấy "tightened and cleaned up" nhưng khi update xong lại bị lỗi. @animret666 báo matrix plugin vẫn broken sau 5 update liên tiếp.

Chốt một câu

OpenClaw 2026.5.7 không phải bản release sexy. Nhưng đây là loại update giúp bạn không phải hét vào máy tính lúc 2 giờ sáng. Boring fixes, useful boring.
