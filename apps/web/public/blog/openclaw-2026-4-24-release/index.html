TL;DR

OpenClaw 2026.4.24 là bản cập nhật với hơn 80 thay đổi: voice calls giờ kết nối được full agent, DeepSeek V4 Flash trở thành model mặc định (kèm V4 Pro), browser automation thêm coordinate clicks, và Google Meet lần đầu tích hợp như bundled plugin. Tuy nhiên, cộng đồng phản ánh nhiều vấn đề sau update — gateway timeout, plugin dependencies lỗi, và Telegram bị ảnh hưởng.

OpenClaw là gì?

OpenClaw là nền tảng AI agent mã nguồn mở phổ biến nhất hiện tại với hơn 364K stars trên GitHub. Được tạo bởi Peter Steinberger (steipete), OpenClaw cho phép bạn chạy AI agent trên máy riêng — kết nối với nhiều model (GPT, Claude, DeepSeek, Gemini), nhiều kênh giao tiếp (Telegram, Slack, Discord, WhatsApp, Voice Call), và hàng trăm plugin/tools.

Khác với các AI agent cloud-based, OpenClaw chạy self-hosted — bạn kiểm soát hoàn toàn dữ liệu, model, và chi phí.

5 điểm nhấn của bản 2026.4.24

📞

Voice Calls → Full Agent

Cuộc gọi thoại giờ có thể chuyển tiếp câu hỏi phức tạp đến full OpenClaw agent. Trước đây voice chỉ xử lý đơn giản — giờ có thể gọi tools, truy cập browser, tìm kiếm web ngay trong cuộc gọi. Tính năng openclaw_agent_consult cho phép realtime voice handoff.

🧠

DeepSeek V4 Flash + Pro

DeepSeek V4 Flash trở thành model onboarding mặc định — nhanh và tiết kiệm hơn. V4 Pro có trong catalog cho heavy tasks. Fix thinking/replay cho follow-up tool-call turns — giải quyết lỗi 400 khi switch model giữa session.

🖱️

Browser Coordinate Clicks

Agent giờ click được bằng toạ độ viewport thay vì chỉ dùng CSS selector. Thêm per-profile headless overrides, stable tab reuse, stale-lock recovery, và action budget tăng lên 60 giây mặc định — không còn timeout sớm khi trang load chậm.

📹

Google Meet Plugin

Lần đầu tiên: Google Meet trở thành bundled participant plugin. Agent tham gia cuộc họp với personal Google auth, hỗ trợ Chrome + Twilio realtime, xuất transcript/recordings/attendance, và doctor/recovery flows tự động.

Điểm 5: Infrastructure gọn hơn

Plugin và model infrastructure được tối ưu: static model catalogs thay vì load runtime, manifest-backed model rows, lazy provider dependencies, và sửa runtime dependency cho packaged installs. Khởi động nhanh hơn, nhẹ hơn. Command gateway status bỏ qua plugin loading, chạy nhanh hơn đáng kể.

Phân tích chi tiết từ Release Notes

Voice & Realtime

Đây là thay đổi lớn nhất về kiến trúc. OpenClaw giờ có:

  • Browser WebRTC realtime voice sessions — backed bởi OpenAI Realtime API, với Gateway-minted ephemeral client secrets
  • Gemini Live realtime voice provider — cho backend Voice Call và Google Meet audio bridges, hỗ trợ bidirectional audio + function-call
  • Voice Call setup & smoke test — voicecall setup và voicecall smoke (dry-run) để kiểm tra Twilio readiness trước khi gọi thật
  • Talk và Voice Call consult full agent — realtime voice loop có thể hỏi agent backend khi cần tool-backed answers

Browser Automation

Một loạt cải thiện thực tế:

  • Coordinate clicks: openclaw browser click-coords cho CLI, viewport coordinate clicks cho managed + existing sessions
  • Action timeout 60s mặc định: Không còn lỗi timeout khi trang load lâu — trước đây mặc định ngắn hơn nhiều
  • Per-profile headless: Một profile chạy headless mà không ảnh hưởng profile khác
  • Stale lock recovery: Tự dọn Chromium Singleton* locks sau crash, retry launch 1 lần
  • Deduplicate lazy-start: Fix race condition gây duplicate Chrome launches

Model & Provider

  • DeepSeek V4 Flash + Pro vào bundled catalog, V4 Flash = onboarding default
  • Fix reasoning_content placeholders cho replayed assistant tool-call turns — giải quyết lỗi 400 khi switch sang DeepSeek V4 mid-session
  • Gemini: retry reasoning-only, empty, và planning-only turns thay vì stall silent
  • /models add bị deprecate — khuyến khích dùng catalog thay vì config thủ công

Fixes quan trọng

  • MCP: Retire one-shot embedded MCP runtimes, skip bundle-MCP startup khi tool allowlist không reach, thêm idle eviction — fix 4 issues liên quan memory leak
  • Heartbeat: Fix crash loop khi every value vượt Node timeout cap, stop inject heartbeat prompt vào non-heartbeat runs
  • Telegram: Suppress phantom "Agent couldn't generate a response" fallback sau khi reply đã committed
  • WhatsApp TTS: Preserve audioAsVoice cho voice-note intent
  • Sessions/subagents: Fix stale ended runs reappearing, recover child sessions sau transport failures

Breaking Change

Plugin SDK: registerEmbeddedExtensionFactory bị xoá

Path compatibility api.registerEmbeddedExtensionFactory(...) chỉ dành cho Pi đã bị loại bỏ. Plugins phải chuyển sang api.registerAgentToolResultMiddleware(...) với contracts.agentToolResultMiddleware. Đây là thay đổi duy nhất có thể break plugins cũ.

Đánh giá tổng thể

Release lớn, nhưng update với cẩn thận

Đây là bản cập nhật tham vọng nhất của OpenClaw trong thời gian gần đây — voice calls reach full agent, Google Meet integration, DeepSeek V4 làm default, browser automation mạnh hơn. Tuy nhiên, pattern "update rồi fix" lặp lại: nhiều user gặp lỗi gateway, plugin deps, và Telegram ngay sau update.

Khuyến nghị: Nếu đang chạy production workloads, chờ 1-2 ngày cho hotfix trước khi update. Nếu đang dev/test, update ngay để trải nghiệm voice calls và DeepSeek V4 Flash. Backup config trước khi update: cp -r ~/.openclaw ~/.openclaw-backup.

Cách update

Nếu đã cài OpenClaw qua npm:

# Backup trước
cp -r ~/.openclaw ~/.openclaw-backup

# Update
npm update -g openclaw

# Hoặc pull latest từ GitHub
git pull origin main && npm install

# Verify
openclaw --version
# Expected: 2026.4.24
