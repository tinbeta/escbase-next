Anthropic Blueprint: Dùng Claude Code Xây Công Ty Với Nhân Viên Là AI, CEO Ngủ

04/05/2026 10 phút đọc AI Agents, Anthropic, Claude Code

TL;DR

Anthropic vừa công bố blueprint chính thức để xây công ty với Claude Code: 1 CEO người (có thể ngủ) + nhiều AI agent làm việc tự động. Agent Stack (ADK + Vertex AI + MCP + A2A) giải quyết 3 vấn đề lớn: quá nhiều framework không tương thích, agent không giao tiếp được với nhau, và quản lý production cực khó. Cấu trúc công ty AI đang dần thành hiện thực.

Video tóm tắt từ @Jouhatsu_ai — Anthropic blueprint chi tiết.

Bối cảnh: 3 vấn đề chết người khi deploy AI vào production

Jouhatsu_ai, người đã tóm tắt guide này, chỉ ra rằng trước khi có Agent Stack, có 3 vấn đề lớn:

  1. Quá nhiều framework khác nhau → tích hợp thành ác mộng
  2. Agent từ framework khác nhau không giao tiếp được với nhau
  3. Quản lý production (monitoring, logs, governance) là địa ngục

Agent Stack: 4 thành phần, 1 kiến trúc

① ADK (Agent Development Kit)

Bộ công cụ để tạo agents. Open source, code-first.

② MCP (Model Context Protocol)

Standard kết nối agent với tools bên ngoài.

③ Vertex AI Agent Engine

Nền tảng deploy production tự động (managed).

④ A2A (Agent-to-Agent)

Giao thức cho phép agent từ framework khác nói chuyện.

Tất cả đặt trên nền tảng Claude models.

ADK: Cần chỉ 3 file để tạo agent đầu tiên

Theo guide, chỉ cần:

  • agent.py — logic của agent
  • .env — biến môi trường (API keys, configs)
  • __init__.py — file chuẩn Python

Ví dụ agent cơ bản:

LLMAgent(
  name="birthday_planner",
  model=Claude("claude-sonnet-4-5"),
  description="Planifie des fêtes",
  instruction="Gère la liste d'invités et propose des idées"
)

Chạy adk run birthday → agent chạy ngay từ terminal.

4 concepts cốt lõi trong ADK

  1. Agent = bộ não chạy trên LLM
  2. Tool = các kỹ năng/capabilities cho agent
  3. Runner = điều phối agent, quản lý sessions
  4. Session = bộ nhớ hội thoại (nhớ context)

4 patterns workflow để orchestration agent

  • LLM Agent — 1 LLM tự quyết định (max flexibility)
  • Sequential Agent — nhiều agent chạy nối tiếp A → B → C
  • Parallel Agent — nhiều agent chạy song song (tiết kiệm thời gian)
  • Loop Agent — lặp đến khi điều kiện được thỏa (retry tự động)

Pre-built tools: Google Search, Vertex AI Search, Code Execution

ADK cung cấp sẵn tools mạnh:

  • Google Search — tìm kiếm web thời gian thực
  • Vertex AI Search — tìm trong dữ liệu nội bộ (docs, database)
  • Code Execution — chạy Python (tính toán, chart, transform)
  • Built-in Agent Tools — gọi các agent ADK khác như tool

MCP: Kết nối tools bên ngoài chỉ 2 dòng code

MCP là standard giúp agent kết nối bất kỳ tool nào:

MCPToolset.from_server(...)

Tất cả servers MCP trên thị trường đều trở thành tools của bạn.

Multi-agent: Cấu trúc công ty thu nhỏ trong code

Ví dụ: Birthday Planner trở thành:

  • Agent "Creativity & Ideas"
  • Agent "Reservation & Calendar"

Orchestrator agent tự đọc câu hỏi → quyết định ai competent → delegate tự động. Đây là cấu trúc công ty được dịch sang code.

Debug với Web UI: adk web

Command adk web mở dashboard trong trình duyệt, thấy:

  • Agent nào được activate và tại sao
  • Quá trình suy nghĩ hoàn chỉnh
  • Mỗi tool call theo thứ tự
  • Luồng giữa các agents trong architecture multi-agent

Deploy production: agent_engine.create()

Thay vì phải setup server web, Docker, infra cloud, monitoring — chỉ cần:

agent_engine.create()

Monitoring, logs, auto-scaling → tất cả được managed. Deploy agent như push file.

A2A Protocol: LangGraph, LangChain, CrewAI nói chuyện được với nhau

Ba framework kia mỗi cái có dialect riêng. A2A là ngôn ngữ chung kết nối tất cả.

Chốt một câu

Anthropic không chỉ build model, họ đang xây infrastructure cho "công ty AI" thực sự. ADK + Vertex AI + MCP + A2A = stack hoàn chỉnh để 1 người điều hành hệ thống nhiều agent tự vận hành. "Công việc đang chết dần" nghe dramatic, nhưng blueprint này đang biến nó thành thực tế kỹ thuật có thể triển khai được.
