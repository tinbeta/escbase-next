23|## Grok 4.3 Chính Thức Là Default xAI Model

24|

25|Mặc dù Grok 4.3 mới ra mắt từ 30/4, OpenClaw nhanh chóng đưa nó vào bundled catalog và đặt làm default chat model cho provider xAI. Đây là default hợp lý vì Grok 4.3 vừa có Intelligence Index 53, vừa có giá rẻ ($1.25/$2.50) — lý tưởng cho daily driver workflows.

32|## Plugin System Cải Thiện Sturdier

33|

34|"Big plumbing pass" cho plugins — đây là cải thiện quan trọng vì plugins là xương sống của OpenClaw's extensibility:

35|

36|- npm-first installs: Ưu tiên npm install, fallback nếu fail

37|- Beta fallback: Có thể chọn beta channels nếu stable failure

38|- Doctor repair: Auto-diagnose và fix plugin issues

39|- Dependency state tracking: Biết rõ plugin đang dùng version nào

40|- ClawHub metadata: Lấy metadata từ hub đáng tin cậy

41|- Fewer runtime loads on hot paths: Giảm overhead khi chạy agent

42|

43|Điều này giải quyết một trong những pain point lớn: plugin breaking sau mỗi update.

44|

45|## Gateway & Agent Hot Paths Leaner

46|

47|Hiệu năng runtime được tối ưu:

48|

49|- Faster startup: Khởi động agent nhanh hơn

50|- Lighter session listing: Danh sách session nhẹ nhàng hơn

51|- Cached tool descriptors: Tool metadata được cache, tránh fetch lại

52|- Less broad plugin loading: Chỉ load plugin cần thiết cho task

53|- Fewer stalls on large configs: Cấu hình lớn không làm chậm hệ thống

54|

55|Đây là những thay đổi "boring but essential" — không sexxy như model mới, nhưng giúp OpenClaw chạy production 24/7 ổn định hơn.
