open-slide: Framework Làm Slide Dành Riêng Cho AI Agents (Claude, Cursor, Codex)

03/05/2026 8 phút đọc AI Tools, Presentation, Agents

TL;DR

open-slide là slide framework được xây dựng dành riêng cho AI agents: chỉ cần prompt agent, nhận polished deck. Mỗi slide là React component trên canvas 1920×1080. Có sẵn agent skills như /create-slide (tạo deck từ 1 dòng prompt), /apply-comments (áp dụng feedback in-browser chỉ 1 click). Hỗ trợ presenter mode, export PDF/HTML, deploy Vercel/Netlify. Hoạt động tốt với Claude Code, Cursor, Codex.

Demo video từ thread @1weiho — open-slide trong thực tế với agent.

Vấn đề open-slide giải quyết

Nhiều người dùng agent để "make me slides about X" nhưng kết quả thường là output thô, thiếu polish, và phải copy-paste feedback nhiều vòng. open-slide đóng vai trò missing runtime giữa prompt và deck chuyên nghiệp.

Các tính năng nổi bật

🎨 Mỗi slide = React component

1920×1080 canvas, dễ customize và version control.

💬 In-browser inspector

Click element → comment "make this red" → /apply-comments → agent áp dụng hết.

🎤 Presenter mode

Speaker notes + timer sẵn có.

📦 Export & Deploy

Static HTML, PDF, 1-click Vercel/Netlify/Cloudflare.

Agent skills tích hợp sẵn

  • /create-slide — Draft full deck từ 1 dòng prompt
  • /apply-comments — Áp dụng toàn bộ feedback in-browser chỉ 1 lần chạy

Không còn phải copy-paste feedback vào chat. Agent có thể tự đọc comment và update slide ngay.

Chốt một câu

open-slide không phải là công cụ thay thế PowerPoint/Keynote, mà là bridge giữa AI agent và presentation chuyên nghiệp. Nó giải quyết pain point thực tế: agent giỏi sinh nội dung, nhưng thiếu runtime để biến output thành deck đẹp, có cấu trúc, dễ chỉnh sửa và deploy. Với open-slide, workflow "prompt → polished deck" trở nên thực tế hơn bao giờ hết.
