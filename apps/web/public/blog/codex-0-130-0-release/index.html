Codex 0.130.0: Remote Control, Plugin Hooks Và Bedrock Auth

09/05/2026 4 phút đọc Codex, CLI, AWS, Plugin

TL;DR

Codex 0.130.0 vừa ra mắt với codex remote-control — entrypoint đơn giản cho headless remotely controllable app-server, plugin hooks hiển thị trong plugin details, và Bedrock auth hỗ trợ AWS console-login credentials. Nhiều fix cho app-server threads và Windows sandbox.

🚀 codex remote-control

Command mới codex remote-control là top-level entrypoint để khởi động headless, remotely controllable app-server. Điều này đơn giản hóa việc setup server có thể điều khiển từ xa — không cần config phức tạp.

@morganlinton phản ứng: "Remote control 👀" — đúng, đây là feature đáng chú ý cho ai cần điều khiển Codex từ xa.

🔌 Plugin Hooks Và Sharing

Plugin details giờ hiển thị bundled hooks — bạn có thể thấy chính xác plugin đang hook vào đâu. Plugin sharing cũng expose link metadata và discoverability controls, giúp quản lý plugin dễ hơn.

☁️ Bedrock Auth Với AWS Console Credentials

Bedrock auth giờ có thể dùng AWS console-login credentials từ aws login profiles. Điều này đơn giản hóa việc authenticate với AWS Bedrock — không cần setup API keys riêng nếu bạn đã có AWS CLI profile.

view_image cũng được cải thiện: resolve files qua selected environment cho multi-environment sessions.

🛠️ App-Server Improvements

  • Live config changes: App-server threads giờ pick up config changes mà không cần restart
  • Accurate turn diffs: Turn diffs stay accurate across apply-patch operations, kể cả partial failures vẫn mutated files
  • Remote compaction: Emits response.processed cho v2 streams, omit service_tier trên API-key compact requests
  • Windows sandbox: Grant sandbox users access to desktop runtime binary cache

🎯 App-Server Clients

Clients có thể page large threads với unloaded, summary, hoặc full turn item views. Điều này cải thiện performance khi làm việc với threads dài — không cần load toàn bộ history.

Chốt một câu

Codex 0.130.0 không phải bản release lớn với feature sexy, nhưng tập trung vào độ tin cậy và integration. Remote control đơn giản hóa deployment, plugin hooks tăng transparency, Bedrock auth giảm friction với AWS. Đây là loại update giúp Codex trở thành công cụ production-ready hơn.
