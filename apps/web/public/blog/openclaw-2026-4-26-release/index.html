OpenClaw 2026.4.26: Browser Talk, Cerebras, UI Diff Panel và Hơn Nữa

Apr 26, 2026 8 min read OpenClaw, AI Tools, DevTools

TL;DR

OpenClaw 2026.4.26 bổ sung Browser Realtime Talk ( voice chat trực tiếp trong browser ), Provider Cerebras mới, memory asymmetric embeddings, UI diff panel cho config raw, và Claude importer để di chuyển workspace. Đây là bước tiến rõ rệt từ assistant sang production-ready AI system.

🎯 OpenClaw là gì và tại sao bản 2026.4.26 quan trọng?

OpenClaw là AI agent framework tập trung vào workflow tự động hóa — từ coding, research đến voice interaction. Nếu bạn đã dùng Claude Code hay các coding assistants, OpenClaw là "bản nâng cấp" cho production: nhiều provider, memory vectors, realtime voice, và security hardening.

Bản 2026.4.26 không phải hot-fix nhỏ. Đây là bản cải tiến toàn diện kiến trúc — tách biệt browser talk, mở rộng providers, tối ưu memory retrieval, và thêm công cụ quản lý config. Nếu bạn đang xây agent cho team, bản này đáng để nâng cấp ngay.

Browser Talk — Voice agent không cần app ngoài

Trước đây, voice plugins cần client app riêng (điện thoại/desktop). Bản 2026.4.26 giới thiệu Google Live Talk và Gateway relay — agent có thể nói chuyện với bạn trong browser tab. Kết quả:

  • Không cần cài đặt — user mới dễ tiếp cận
  • Low-latency — relay backend tối ưu
  • Scalable — nhiều user cùng lúc trên cùng instance

Cerebras provider — Mở rộng model options

Provider Cerebras được thêm dưới dạng bundled plugin với:

  • Onboarding flow có sẵn
  • Static model catalog
  • Manifest-owned endpoint metadata
  • Không cần config thủ công

Nếu bạn cần inference tốc độ cao với model lớn, Cerebras là lựa chọn mới.

Memory enhancements — Tìm kiếm thông minh hơn

Bản này bổ sung memorySearch.inputType, queryInputType, documentInputType — cho phép asymmetric embedding endpoints:

  • Query embeddings khác với document embeddings
  • Batch indexing nhanh hơn với provider-specific prefixes
  • Hỗ trợ nomic-embed-text, qwen3-embedding, mxbai-embed-large ra hộp

UI/UX polish — Raw config diff & Quick Settings

Hai cải tiến UI nhỏ nhưng có ý nghĩa lớn:

  1. Raw config diff panel: parse JSON5, redact sensitive values đến khi reveal, tránh fake edit callbacks — an toàn hơn khi sửa config.
  2. Quick Settings dashboard grid: cards căn chỉnh đồng bộ desktop/tablet/mobile, tiết kiệm space.

Matrix E2EE — Bảo mật end-to-end

Command openclaw matrix encryption setup cho phép:

  • Enable Matrix encryption cho chat
  • Bootstrap recovery key
  • Print verification status

Tất cả trong 1 flow — không cần config thủ công multiple files.

Agents Compaction — Giữ system nhẹ nhàng

agents.defaults.compaction.maxActiveTranscriptBytes là preflight trigger — khi active JSONL transcript quá lớn, tự động rotát sang file mới nhỏ hơn thay vì byte-splitting bruteforce. Quan trọng với agent long-running.

Claude Importer — Di chuyển workspace lightning fast

Bundled importer cho phép:

  • Preview & apply Claude Code settings
  • Transfer Claude Desktop instructions
  • Migrate MCP servers, skills, command prompts
  • Tự động archive & manual fallback

Nếu bạn đang dùng Claude Code/Desktop, đây là must-use tool để chuyển workspace.

🔍 So sánh: Trước vs Sau (Nên/Không nên)

✅ Nên nâng cấp lên 2026.4.26 nếu:

  • Bạn dùng voice/audio plugins — Browser Talk giảm latency đáng kể
  • Cần provider mới — Cerebras sẵn sàng, không cần config
  • Agent của bạn chạy session dài — compaction ngăn memory leak
  • Bạn muốn di chuyển từ Claude Desktop — importer cứu cánh

❌ Cân nhắc kỳ nếu:

  • Agent của bạn phụ thuộc vào custom plugin chưa compatible với manifest mới
  • Bạn đang chạy config legacy — cần test trên staging trước
  • Matrix E2EE chưa cần thiết — có thể bỏ qua

💡 Lưu ý

Một số thay đổi (như plugin manifest normalization) có thể ảnh hưởng backward compatibility. Luôn test trên non-production trước khi deploy production agents.

  • Cerebras → Inference options mở rộng
