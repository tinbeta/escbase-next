🧭 Claude Code Agent View: Mission Control Cho Multi-Agent Session

12/05/2026 5 phút đọc Claude, Anthropic, Agent, CLI

TL;DR

Claude Code ra mắt Agent View: một danh sách duy nhất quản lý tất cả session. Chạy nhiều agent song song, xem trạng thái running/waiting/done, reply inline để unblock, nhảy vào/ra bất kỳ session mà không mất vị trí.

@claudeai vừa thông báo một feature mới cho Claude Code: Agent View — một dashboard xem tất cả session trong một danh sách duy nhất. Đây là research preview, available ngay trên tất cả paid plans.

🖼️ Screenshot Gốc Từ @claudeai

🎯 Agent View Là Gì?

Claude Code giờ cho phép bạn:

  • Chạy nhiều session song song: claude agents để dispatch nhiều session cùng lúc. Mỗi session chạy riêng không chiếm terminal tab.
  • Xem trạng thái tổng quan: Cái nào đang chạy, cái nào đang chờ bạn, cái nào đã xong — nhìn một cái là biết.
  • Reply inline: Trả lờì trực tiếp để unblock agent mà không cần switch tab.
  • Nhảy vào/ra: Vào bất kỳ session nào để xem chi tiết, rồi nhảy ra không mất vị trí.

🎯 Chốt Một Câu

Claude Code Agent View không chỉ là một UI improvement — đó là nhận thức rằng coding trong kỷ nguyên agent không phải một session mà là nhiều session chạy song song. Và khi bạn có nhiều agent cùng lúc, cái bạn cần không phải thêm agent nữa, mà là cách nhìn thấy tất cả chúng cùng một lúc. Đó là lý do một danh sách session đơn giản lại là feature devs không nhận ra mình cần — cho đến khi họ có nó.
