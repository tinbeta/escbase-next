🚀 Claude Code 2.1.139: /goal Chính Thức Ra Mắt, Agent View Và 50+ Cập Nhật

12/05/2026 4 phút đọc Claude Code, AI, Agent, Coding

TL;DR

Claude Code 2.1.139 ra mắt với 50+ thay đổi CLI và 1 cập nhật system prompt. Điểm nhấn: /goal command để chạy task xuyên nhiều turn, agent view để quản lý tất cả session, system prompt compaction giờ silent, và nhiều fix bảo mật/quan trọng.

Claude Code Changelog vừa công bố phiên bản 2.1.139 với 50+ thay đổi CLI và 1 cập nhật system prompt. Đây là bản cập nhật lớn nhất trong thờì gian gần đây, mang đến những tính năng mà cộng đồng developer đang mong chờ.

🎬 Video Demo /goal Từ Chủ Thread

🎯 /goal Command: Game Changer

Tính năng đáng chú ý nhất: /goal command — cho phép đặt một completion condition và Claude tự động làm việc xuyên nhiều turn cho đến khi đạt được mục tiêu.

  • Hoạt động trong interactive mode, -p mode, và Remote Control.
  • Hiển thị live elapsed/turns/tokens như một overlay panel.
  • Agent tự động phân rã task và thực thi tuần tự.

👁️ Agent View (Research Preview)

Một danh sách duy nhất hiển thị mọi Claude Code session — đang chạy, đang chờ bạn, hoặc đã hoàn thành. Chạy claude agents để bắt đầu.

🔧 Các Cập Nhật Quan Trọng Khác

  • /scroll-speed — điều chỉnh tốc độ scroll chuột với live preview.
  • claude plugin details — hiển thị component inventory và chi phí token per-session.
  • Transcript view navigation — phím tắt ?, {/} để jump giữa các prompt, v để toggle shortcut panel.
  • Hook args: string[] — spawn command trực tiếp không qua shell.
  • Hook continueOnBlock — cho phép hook rejection reason được feedback lại Claude và continue turn.

🔒 Thay Đổi Bảo Mật Quan Trọng

Remote Control, /schedule, MCP connectors, và notification preferences giờ bị vô hiệu hóa khi ANTHROPIC_API_KEY / apiKeyHelper / ANTHROPIC_AUTH_TOKEN được set — ngay cả khi có https login. Để dùng các tính năng này, cần unset API key.

📝 System Prompt Cập Nhật

Thay đổi đáng chú ý trong system prompt: Claude không còn được explicitly thông báo rằng long chats trigger automatic context compaction. Điều này giảm việc model proactively preserve key details, vì harness-level reminder đã biến mất.

Compaction prompt giờ yêu cầu model preserve sensitive user instructions, giảm mất ý định của ngườì dùng trong quá trình trimming.

🐛 Các Fix Đáng Chú Ý

  • Deadlock fix: Expired credentials và forceRemoteSettingsRefresh không còn block claude auth login/logout/status.
  • autoAllowBashIfSandboxed giờ auto-approve cả commands có shell expansions như $VAR và $(cmd).
  • Unbounded memory growth fix khi HTTP/SSE MCP server stream non-protocol data — response bodies giờ capped ở 16 MB per SSE frame.
  • Skill(name *) wildcard form giờ hoạt động đúng như prefix match.
  • Hyperlinks giờ adapt theo active theme thay vì dùng dark navy trên dark themes.
  • Mouse wheel scrolling fixed trong Cursor và VS Code 1.92–1.104.

🎯 Chốt Một Câu

Claude Code 2.1.139 không chỉ là một bản cập nhật thông thường — nó là bước chuyển mình từ "chat với AI" sang "giao việc cho AI và để nó tự hoàn thành." Với /goal, agent view, và hàng loạt cải tiến về UX và bảo mật, Claude Code đang trở thành một agent IDE thực thụ. Câu hỏi không còn là "Claude có thể viết code không?" mà là "Claude có thể tự quản lý project của bạn trong nhiều ngày mà không cần bạn phải ngồi chờ từng bước không?"
