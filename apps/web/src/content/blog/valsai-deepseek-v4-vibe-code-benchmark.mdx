Vals AI vừa đưa DeepSeek V4 lên vị trí #1 open-weight model trên Vibe Code Bench v1.1 với 49.93%, bỏ xa Kimi K2.6 ở vị trí #2 với khoảng cách 12.04 điểm. Điều đáng nói không chỉ là top 1 open model, mà là benchmark này đo khả năng xây web app từ đầu với pipeline đánh giá tự động khá nặng tay.
